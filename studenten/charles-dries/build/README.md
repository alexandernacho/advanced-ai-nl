# Eventreactiesorteerder

## Wat doet de tool?

De tool geeft één bezoekersreactie precies één label en een korte reden. De labels kunnen nadien geteld worden om de vaakst genoemde verbeterpunten voor een event te zien.

## Zo test je de tool

1. Open een nieuw tijdelijk gesprek zonder web search.
2. Plak de inhoud van `prompt.md`.
3. Vervang de tekst onder `REACTIE` door één testreactie.
4. Vergelijk het label met het vooraf bepaalde juiste antwoord in `test-set.md`.
5. Noteer het resultaat in `log.md`.
