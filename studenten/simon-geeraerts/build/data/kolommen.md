# Kolommen in `bestellingen.xlsx`

| Kolom | Betekenis |
| --- | --- |
| Bestelbonnummer | Het unieke nummer op de bestelbon van de klant: precies vijf cijfers. |
| Naam | Naam waarop de wagen besteld is. |
| Wagen | Merk, model en uitvoering. |
| Status | Huidige fase van de bestelling, bijvoorbeeld `In productie`, `Onderweg naar de garage` of `Vertraagd bij transport`. |
| Verwachte aankomst | Verwachte datum waarop de wagen bij de garage aankomt. Dit is geen afhaaldatum. |
| Ombouw | `Ja` of `Nee`; bijvoorbeeld voor een trekhaak, bedrijfsinrichting of andere aanpassing. |
| Opmerking ombouw | Wat nog met de ombouwer afgestemd moet worden. Leeg wanneer er geen ombouw is. |
| Laatst bijgewerkt | Datum waarop de garage deze rij controleerde. |

De assistent heeft minimaal de eerste vijf kolommen nodig. De overige kolommen maken de export realistischer en zijn nuttig voor een volgende versie.
