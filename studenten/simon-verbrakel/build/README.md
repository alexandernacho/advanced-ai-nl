# Defensienieuws-labeler

Deze tool leest de kop en de eerste alinea van één nieuwsbericht en zegt wat het bericht betekent voor de vraag naar defensiebedrijven. Eruit komt één label (positief, negatief, neutraal, niet over defensie of onzeker) met een korte reden. Gebruik: plak prompt.md in een nieuw gesprek en zet het bericht onderaan.
